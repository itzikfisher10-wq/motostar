# בדיקות

```bash
npm run typecheck     # TypeScript strict
npm run lint          # ESLint (Next.js core-web-vitals + TypeScript)
npm test              # Vitest: יחידה + אינטגרציה (בונה מסד motostar_test מאפס)
npm run test:e2e      # Playwright: בונה את האתר, מסד motostar_e2e מאפס, דסקטופ + מובייל
```
דרישה: PostgreSQL מקומי. ברירת המחדל `postgres://postgres:postgres@localhost:5432`; אפשר לשנות עם `TEST_DATABASE_URL` / `E2E_DATABASE_URL`. הסקריפטים **מסרבים** לאפס מסד ששמו לא מסתיים ב-`_test` או `_e2e`.
