# מדריך עריכת קוד — איפה משנים מה

## עמוד הבית
- **סדר האזורים:** `src/app/(store)/page.tsx`. כל אזור הוא רכיב אחד; מוחקים, מוסיפים או מזיזים שורה.
- **האזורים:** `src/components/home/`

| רכיב | מה הוא מציג |
|---|---|
| `helmet3d/HelmetHero.tsx` | הפתיח: תגית, כותרת h1 עם שורה אדומה מתחלפת, כפתורים, קסדת התלת-ממד וכרטיסי זכוכית עם עובדות |
| `VehicleFinder.tsx` | "מה הכלי שלך?": אריח לכל יצרן, והדגמים שלו נפתחים מתחת |
| `ModelsMarquee.tsx` | שמות הדגמים בענק, זזים עם הגלילה (פותח את הקטע הכהה) |
| `AraiExperience.tsx` | פתיח Arai וסיור החלקים הנעוץ (pinned) |
| `AraiRail.tsx` | פס כל חלפי Arai |
| `ProductRail.tsx` + `ScrollRail.tsx` | פס מוצרים (מבצעים, "אולי תצטרכו גם") עם כפתורי דפדוף מזכוכית |
| `CategoryAccordion.tsx` | "מה אתם מחפשים היום?": אקורדיון קטגוריות |
| `WorkshopStrip.tsx` | "מוסכניקים שפתחו חנות" ועובדות שירות |

רכיבים שלא בשימוש כרגע (נשארו לשימוש עתידי): `Manifesto.tsx`, `ShelfPan.tsx`, `VehicleBand.tsx`, `ClosingPlate.tsx`, `CategoryIndex.tsx`.

- **הבריף שמאחורי הסדר והתנועה:** [home-brief.md](home-brief.md). אם מוסיפים אזור, בודקים מולו שאין שני אזורים צמודים עם אותה תנועה.
- **אזורים נעוצים (pinned):** נבנים דרך `src/components/motion/useScrollScene.ts` (GSAP ScrollTrigger). ה-hook טוען את GSAP רק כשצריך, לא בונה כלום כשמבקשים פחות תנועה, וממיין את האזורים לפי המיקום בדף. **כל אזור נעוץ חדש חייב לעבור דרכו**, אחרת סדר הגלילה מתבלגן.
- **גיליונות:** כל אזור אחרי הפתיח מסומן `data-sheet`: פינות עגולות למעלה, ועולה 2rem על האזור הקודם. האזור הראשון אחרי הפתיח עולה 40svh בדסקטופ, כדי לגלוש מעל הבמה הנעוצה.
- **חומרי זכוכית וכפתורים:** `glass-dark` / `glass-light` / `glass-bar` ב-`globals.css`, ווריאנטים `glass` / `glassLight` ב-`Button.tsx`.

## פתיח הבית וקסדת התלת-ממד
- **סדר האזורים:** פתיח, בחירת אופנוע, Arai, מבצעים, קטגוריות, "מוסכניקים". הנימוק בבריף.
- **טקסטים:** `src/content/home.ts` (כל הטקסטים של דף הבית בקובץ אחד). בלי קו מפריד ארוך (em dash), בלי מספרים שלא מגיעים מהמסד. בטקסט הגוף של הפתיח, `{count}` ו-`{makes}` מתמלאים מהקטלוג (מספר המוצרים והיצרנים שיש להם מוצרים), כך שהם תמיד נכונים.
- **הקסדה:** `src/components/home/helmet3d/scene.ts` (three.js). זו קסדה גנרית שבנינו בקוד, **איור של MotoStar ולא דגם של יצרן כלשהו**. מתחתיה מוצג "להמחשה בלבד". אין לקשר אותה למוצר או להציג אותה כפריט במלאי.
- **תנועה:** כניסה (עלייה וסיבוב), סיבוב ופתיחת המשקף עם הגלילה (האזור נעוץ ב-CSS sticky), הטיה קלה לפי העכבר בדסקטופ, וריחוף קצר. הקבועים נמצאים בפונקציה `pose()`.
- **ביצועים:** three.js נטען רק אחרי שהדף נצבע וכשהדפדפן פנוי. הציור נעשה רק כשמשהו זז ונעצר כשהאזור מחוץ למסך. בטלפון יש פחות פוליגונים ו-30 פריימים לשנייה.
- **בלי תלת-ממד:** בדפדפן בלי WebGL, או עם רינדור תוכנה (בלי כרטיס גרפי), מוצגת תמונת סטילס של אותה קסדה: `public/images/hero-helmet.webp`. בהפחתת תנועה, הקסדה עומדת במקום.
- **בדיקה בדפדפן headless** (שאין לו כרטיס גרפי): מוסיפים `?3d=force` לכתובת.
- **החלפה בדגם אמיתי:** אם יתקבל מודל GLB מורשה ומדויק, אפשר לטעון אותו ב-`scene.ts` (`GLTFLoader`) במקום `buildHelmet`.

## אזור Arai
- **טקסטים ומוצרים:** `src/content/arai.ts` — כותרת הפתיח, ארבע תחנות הסיור (משקף, כונסי אוויר, מנגנון, ריפודים) ורשימת המוצרים של כל תחנה לפי slug. מוצר שנמחק או הועבר לארכיון מוסתר אוטומטית.
- **כותרת וטקסט הפתיח** ניתנים לעריכה גם בממשק הניהול → "תוכן האתר" (גובר על הקובץ).
- **מדיה:** ברירת המחדל היא תמונת מוצר אמיתית מהקטלוג. כשיהיה חומר מורשה מ-Arai:
  - **תמונה:** `media: { type: "image", src: "/media/arai/hero.webp", … }`
  - **סרטון:** `media: { type: "video", src: "/media/arai/hero.mp4", poster: "…" }`
  - **סיבוב 360° עם הגלילה:** שמים פריימים ב-`public/media/arai/turntable/0001.webp…0072.webp` ומגדירים `media: { type: "sequence", pathPattern: "/media/arai/turntable/{frame}.webp", frameCount: 72, … }`
  - השתמשו רק בצילום אמיתי של הדגם הנמכר. אין להציג קסדה להמחשה כאילו היא במלאי.

## אנימציות
כל התנועה באתר מוגדרת בקובץ אחד: `src/styles/motion.css`. רכיבים לא כותבים CSS של אנימציה בעצמם. הם מסמנים אלמנט עם עזר מוקלד מ-`src/components/motion/reveal.ts`:
```tsx
import { reveal, revealItem } from "@/components/motion/reveal";
<span {...reveal.wipe}>…</span>                 // ניגוב טיפוגרפי
<ul {...reveal.cascade}><li {...revealItem(i)}>  // פריטים שעולים בזה אחר זה
```
**איך זה עובד:**
- **כניסות** (focus, panel, wipe, grid, cascade): כל אלמנט מופיע בתנועה של כשנייה ברגע שהוא נכנס למסך. את הכניסה למסך מזהה `src/components/motion/RevealObserver.tsx` (IntersectionObserver, כ-1KB), שמותקן פעם אחת ב-layout של החנות. עובד בכל הדפדפנים, כולל Firefox ו-Safari.
- **תנועה צמודה לגלילה** (פרלקסת תמונות, עומק בפתיח, הלוגו בסוף): CSS scroll-driven animations. בדפדפן שלא תומך (Firefox היום), האלמנטים האלה פשוט עומדים במקום.
- **מה שכבר נראה בטעינה** מוצג מיד, בלי אנימציה, כדי לא לעכב את הטעינה (LCP).
- **בלי JavaScript, או כשהמשתמש ביקש פחות תנועה** (הגדרת "אפקטי הנפשה" ב-Windows, או "הפחתת תנועה" באייפון), שום דבר לא מוסתר והדף מוצג רגיל.
- זזים רק transform, opacity, filter ו-clip-path, ולכן אין קפיצות בפריסה (CLS 0).
- **תזמון ומרחקים:** משתנים בראש `motion.css` (`--reveal-duration`, `--reveal-step`, `--rise-distance`, `--focus-blur`).

**לכל אזור בדף הבית יש "מכשיר" אחר**, כדי שהגלילה לא תרגיש חוזרת על עצמה:

| אזור | תנועה | איפה |
|---|---|---|
| פתיח | קסדת תלת-ממד שמסתובבת ופותחת משקף. בדסקטופ הבמה נעוצה, והאזור הבא עולה מעליה והיא נסוגה (מתכווצת, מתעגלת, מתעמעמת) | `helmet3d/scene.ts` → `pose()`, ו-`motion.css` → "Home hero" |
| שורת הכותרת | שורה אדומה מתחלפת פעם אחת (פחות מ-5 שניות) וקו בכתב יד נמתח מתחתיה | `HelmetHero.tsx` → `PHRASE_MS`, `.hero-phrase` |
| בחירת אופנוע | הלוח גדל למקומו, האריחים עולים בזה אחר זה, הדגמים עולים כשבוחרים יצרן | `reveal.panel`, `reveal.cascade`, `sheet-in` |
| דגמים | שתי שורות ענק זזות לכיוונים מנוגדים | `ModelsMarquee.tsx` |
| סיור Arai | הצמדה (pin) והחלפת חלקים בגלילה | `AraiExperience.tsx`: `TOUR_SCROLL_PER_STOP`, `HERO_LIFT` |
| פסי מוצרים | מפל: הכרטיסים עולים בזה אחר זה | `reveal.cascade` |
| קטגוריות | הפאנל הפתוח מתרחב, התוכן שלו עולה פנימה | `[data-accordion-panel]` ב-`motion.css` |
| "מוסכניקים שפתחו חנות" | טקסט בכניסה רכה, כרטיסי העובדות עולים בזה אחר זה | `reveal.focus`, `reveal.cascade` |
| סוף הדף | הלוגו הגדול עולה למקומו | `reveal.close` ב-`Footer.tsx` |
| פוטר | ארבע העמודות עולות בזו אחר זו | `reveal.cascade` |
| מגירת סל / תפריט | `--animate-drawer-in`, `--animate-fade-in` | `globals.css` |

**בכל שאר העמודים:**

| מה | תנועה | עזר |
|---|---|---|
| כותרות עמוד וטקסטים | עולים מטשטוש לחדות (בטלפון בלי טשטוש, כדי לחסוך בביצועים) | `reveal.focus` |
| רשתות מוצרים (קטגוריות, מותגים, מבצעים, חיפוש, דגמים) | הכרטיסים עולים שורה אחרי שורה, והעמודות בשורה מגיעות בזו אחר זו לפי סדר הקריאה. העמודות מחושבות לכל גודל מסך (2/3/4) | `reveal.grid` על ה-`<ul>` |
| תמונה בתוך כרטיס מוצר | פרלקסה עדינה בזמן הגלילה (טאבלט ומעלה) | `reveal.drift`, כבר בתוך `ProductCard` |
| קבוצות (דגמים, קטגוריות, ערוצי קשר, יצרנים) | עולים בזה אחר זה | `reveal.cascade` + `revealItem(i)` |
| עמוד מוצר | תיאור, התאמה ומפרט בכניסה רכה, "אולי תצטרכו גם" במפל | `reveal.focus`, `ProductRail` |
| קופה וסל | רק הכותרת. טופס תשלום לא זז בזמן גלילה, כדי לא לגרום לטעויות | `reveal.focus` |

**כללים:** אין אנימציה זהה על כל אזור, ואין כותרת שמתחילה שקופה (הכותרת הראשית היא ה-LCP). אין "שורה קטנה מעל הכותרת": הכותרת עומדת בפני עצמה.

## צבעים, פונטים ומרווחים
- **צבעים:** בלוק `@theme` ב-`src/styles/globals.css`. כל הרכיבים משתמשים בשמות (`ink`, `graphite`, `paper`, `mist`, `signal`…), כך ששינוי ערך מחליף אותו בכל האתר.
  - `signal` — אדום המותג. לטקסט אדום על רקע בהיר משתמשים ב-`signal-deep`, ועל רקע שחור ב-`signal-bright` (שומר על ניגודיות 4.5:1).
- **פונטים:** `src/styles/fonts.ts` (משפחות ומשקלים) ו-`--font-display` / `--font-sans` ב-`globals.css`. קובצי הפונט נבנים ב-`npm run fonts:build`.
- **גדלי כותרות:** `--text-display-*` ב-`globals.css`.

## Header, Footer ופרטי העסק
- **פרטי העסק** (טלפון, כתובת, שעות, וואטסאפ, אינסטגרם): `src/config/site.ts` — המקום היחיד. משמש גם ל-Footer, לעמוד צור קשר ול-JSON-LD.
- **Header:** `src/components/layout/Header.tsx` (קישורי התפריט הראשי), `CategoryMenu.tsx` (מגה-תפריט), `MobileNav.tsx` (טלפון).
- **פס ההודעה העליון:** בממשק הניהול → "תוכן האתר".
- **Footer:** `src/components/layout/Footer.tsx`.
- **לוגו:** `src/components/layout/Wordmark.tsx` (לוגו טיפוגרפי). להחלפה בקובץ לוגו רשמי — הוראות בראש הקובץ.

## עמודי מידע (משלוחים, תקנון, פרטיות, נגישות, אודות)
`src/content/pages.ts` — טקסטים בלבד. להוספת עמוד: מוסיפים רשומה ל-`PAGES` ולינק ב-Footer.

## מוצרים וקטגוריות
- **הוספת מוצר:** בממשק הניהול → מוצרים → "מוצר חדש" (ראו [admin-guide.md](admin-guide.md)). לא מוסיפים מוצרים בקוד.
- **הוספת קטגוריה:** בממשק הניהול → קטגוריות → "קטגוריה חדשה".
- **שיוך קטגוריות ביבוא:** `scripts/import-products/config/categories.ts` (רק אם מריצים יבוא מחדש).
- **מילים נרדפות לחיפוש** ("ימאהה" = yamaha, "טימקס" = tmax): `src/lib/text/search-normalize.ts` → `SYNONYM_GROUPS`. אחרי שינוי מריצים `npm run catalog:import -- --update-existing`, או שומרים כל מוצר בניהול כדי לבנות מחדש את אינדקס החיפוש.

## הוספת עמוד ניהול
1. שאילתות: `src/features/admin/<תחום>/queries.ts` (עם `import "server-only"`).
2. פעולות: `src/features/admin/<תחום>/actions.ts` — `"use server"`, וכל פונקציה מתחילה ב-`await requireUser("<הרשאה>")`. בדיקה אוטומטית אוכפת זאת.
3. עמוד: `src/app/(admin)/admin/(panel)/<נתיב>/page.tsx`, ולינק במערך `NAV` ב-`(panel)/layout.tsx`.
