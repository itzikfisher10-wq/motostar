# העברת הקטלוג מהחנות הישנה

## מקור הנתונים
- הפיד הציבורי של החנות הישנה (`motostar.co.il/products.json` ו-`/collections.json`), שנלכד ב-26.10.2026.
- כל קובץ אומת מול SHA-256. הנתונים נשמרו בפורמט מקוצר ב-`data/source/` (`products-0..3.json`, `collections.json`).
- **79 רשומות מקור.** זה תואם את "ראה 79 פריטים" שמופיע בעמוד `/collections/all` באתר המקורי.
- **מה הפיד הציבורי לא כולל:** כמויות מלאי (רק "זמין או לא"), עלויות, משקלים מלאים וברקודים. לכן ספירת המלאי מתחילה **כבויה**, וזמינות כל וריאציה נלקחה כפי שהופיעה במקור. שום נתון לא הומצא.
- **ייצוא רשמי:** אם יש גישה לממשק Shopify הישן, מומלץ לייצא משם CSV מלא של מוצרים ומלאי. כך אפשר לקבל כמויות וברקודים, ולהשוות אותם מול הנתונים שיובאו.

## תהליך היבוא
```bash
npm run catalog:import -- --dry-run          # ניתוח ודוח בלבד
npm run catalog:import                       # יבוא: מוצרים קיימים מדולגים
npm run catalog:import -- --update-existing  # רענון מחירים וטקסטים של מוצרים קיימים
npm run catalog:validate                     # בדיקת תקינות במסד
```
1. **ולידציה** של כל רשומה (Zod). רשומה פגומה עוצרת את היבוא עם הודעה מפורשת.
2. **נרמול:** מחירים לאגורות, ניקוי תיאורים (HTML מותר בלבד), זיהוי מותג ומקור (מקורי או חליפי), מפרט טכני.
3. **זיהוי כפילויות**, דוח ואיחוד (פירוט בהמשך).
4. **כתיבה למסד** בעסקה אחת. כל רשומת מקור נשמרת ב-`source_records` עם hash של התוכן, ולכן הרצה חוזרת לא יוצרת כפילויות.
5. **פלטים:**
   - `reports/catalog-import.md` (קריא)
   - `reports/catalog-import.json`
   - `src/content/generated/legacy-redirects.json` (45 הפניות של collections ועמודים)
   - כתובות המוצרים הישנות (54) נשמרות במסד ב-`product_slug_history`. האתר מפנה אותן בהפניה אחת לכתובת הנוכחית של המוצר, גם אם השם שלו ישתנה בעתיד.

## חוקי איחוד — "שם זהה" אינו מספיק
המערכת **מזהה** מועמדים לאיחוד אוטומטית: שם מנורמל זהה, SKU משותף, תמונה משותפת, תוכן זהה. אבל היא **מאחדת רק מה שהוגדר ידנית** ב-`scripts/import-products/config/merge-groups.ts`, עם ראיה מהמקור לכל ערך.

| מצב | מה קורה |
|---|---|
| אותו מוצר בדיוק (כותרת, SKU, תיאור ומחיר זהים) | מוצג פעם אחת. הרשומה הכפולה נשמרת לביקורת |
| אותו מוצר בצבעים שונים | מוצר אחד עם בחירת צבע |
| מוצרים שונים עם שם דומה (למשל משקף מעושן מול משקף כהה) | נשארים נפרדים |
| אין ודאות | מסומן "לבדיקה ידנית" ולא מאוחד |

נתוני מקור לא נמחקים אף פעם.

## 12 הפריטים שמחכים להחלטה שלכם
מסוננים בניהול: מוצרים → "לבדיקה ידנית בלבד".
- **שמני Motul 5100 (4 מוצרים):** לאחד למוצר אחד עם בחירת נפח (1 ליטר / 4 ליטר) לכל צמיגות? בנוסף, בשמן 10W50 4 ליטר הכותרת אומרת 10W50 אבל התיאור אומר 10W40.
- **מצבר BTX5L-BS:** אוחד משתי רשומות זהות. לוודא שזה אותו מצבר ולא שני ספקים.
- **משענות Xmax (2 מוצרים):** חולקים SKU אחד במקור. צריך לתת לכל אחד SKU ייחודי.
- **סנדלי סחיבה (2 מוצרים):** במקור היו בקטגוריית בלמים, והועברו להנעה. לאשר.
- **סטרטר Sym Joyride:** המקור לא ציין גרסה (125/200, S/EVO).
- **דיסק קדמי Sym Joyride S:** המקור לא ציין נפח מנוע.
- **מחזיר שמן בולם קדמי Xmax 300:** במקור לא הייתה קטגוריה; שויך לחלקי חילוף.

## התאמה לאופנוע
ההתאמות חולצו ידנית מהכותרת והתיאור של כל מוצר (`scripts/import-products/config/fitments.ts`), עם ציטוט הראיה. **כולן מסומנות "לפי המוכר"** ולא "מאומת", כי אף אחד לא בדק מק״ט יצרן. באתר הן מוצגות עם המלצה לבדוק לפני הזמנה. בעל העסק יכול לסמן התאמה כ"מאומת" בניהול, אחרי בדיקה.

## כתובות שהוחלפו בחנות הישנה
בחנות הישנה שני מצברים קיבלו כתובות "הפוכות": המצבר **BTX14-BS** היה בכתובת `/products/מצבר-btx14`, והמצבר **BTX14** בכתובת `/products/מצבר-btx14-bs`. היבוא שומר את הקשר הנכון: כל כתובת ישנה מפנה למוצר שהיה בה בפועל. בנוסף, כתובת חדשה לעולם לא משתמשת בכתובת ישנה של מוצר אחר. בדיקות אוטומטיות שומרות על זה.

## תמונות
**הושלם.** כל 106 תמונות הקטלוג הועתקו לשרת שלנו, ל-`public/images/products/<hash>/` (WebP, כ-4.7MB בסך הכול), והמסד מצביע עליהן. הכתובת המקורית נשמרת ב-`source_url`. `cdn.shopify.com` הוסר מ-CSP ומ-`images.remotePatterns`. `catalog:validate` מראה 0 תמונות ב-Shopify.

שתי דרכים להריץ שוב (למשל אחרי יבוא חוזר):
```bash
npm run catalog:mirror-images                              # הורדה ישירה (דורש גישה ל-cdn.shopify.com)
npx tsx scripts/import-products/mirror-images.ts --from-bundle images.json   # מקובץ JSON מוכן {url: {data(base64), w, h}}
```
קובץ שכבר קיים לא יורד שוב; רק השורה במסד מתעדכנת.
