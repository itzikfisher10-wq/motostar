# SEO טכני

## מה מיושם (ונבדק אוטומטית ב-`tests/e2e/seo.spec.ts`)
| נושא | יישום |
|---|---|
| רינדור | עמודי קטלוג נבנים בשרת (SSG/ISR, רענון כל 5 דקות ומיד אחרי שינוי בניהול) — גוגל מקבל HTML מלא |
| Metadata | לכל עמוד כותרת ייחודית, תיאור, canonical מוחלט, Open Graph ו-Twitter (`src/lib/seo/metadata.ts`). מוצרים וקטגוריות: שדות SEO שנערכים בניהול |
| כותרות | H1 אחד בכל עמוד, H2/H3 בהיררכיה |
| עברית | `lang="he" dir="rtl"`, כתובות עבריות מקודדות נכון, `og:locale=he_IL` |
| Sitemap | `/sitemap.xml` דינמי: עמודים קבועים, קטגוריות עם מוצרים, מותגים, כל המוצרים הפעילים עם `lastModified`. קטגוריות ריקות לא נכללות (ומסומנות noindex) |
| robots.txt | חוסם `/admin`, `/api/`, `/cart`, `/checkout`, `/order/`, `/search`; מפנה ל-sitemap |
| Structured Data | `OnlineStore`+`AutoPartsStore` (כתובת, שעות, מדיניות החזרה), `WebSite`+`SearchAction`, `Product` / `ProductGroup` עם `Offer` לכל וריאציה (מחיר, מטבע, זמינות), `BreadcrumbList`, `ItemList` ברשימות. **אין דירוגים או ביקורות מומצאים** |
| פרמטרים וסינון | עמודים מסוננים/ממוינים: `noindex` + canonical לכתובת הנקייה. חיפוש: noindex |
| תוכן כפול | מוצר אחד = כתובת אחת; צבעים הם וריאציות (`?variant=` לא נוצר כעמוד נפרד) |
| 404 | מוצר/קטגוריה שלא קיימים מחזירים 404 אמיתי |
| הפניות | כל כתובת ישנה של Shopify מקבלת 301 אחד: 54 כתובות מוצר נשמרות כהיסטוריית slugs במסד ומופנות לכתובת **הנוכחית** של המוצר (גם אחרי שינוי שם בניהול); 45 כתובות collections ועמודים בקובץ הפניות; גם `/collections/x/products/y` וקידומות `/en` `/ar`. בדיקה אוטומטית: הפניה אחת, בלי שרשראות ולולאות, כל יעד מחזיר 200 |
| תמונות | `next/image`: AVIF/WebP, גדלים רספונסיביים, lazy-loading מחוץ למסך, `alt` לכל תמונה (נערך בניהול) |
| ביצועים | ראו [performance.md](performance.md) |
| נגישות | axe (WCAG 2.1 AA) ללא הפרות חמורות בעמודים המרכזיים |
| שיתוף | תמונת שיתוף ברירת מחדל (`src/app/opengraph-image.png`), אייקונים (`icon.svg`, `apple-icon.png`) |

## מה נדרש מבעל העסק
- אימות האתר ב-Google Search Console והגשת ה-sitemap (ראו [deployment.md](deployment.md#מעבר-הדומיין-מ-shopify-בלי-לאבד-תנועה-אורגנית)).
- Google Business Profile: לוודא שהכתובת, הטלפון והשעות זהים ל-`src/config/site.ts`. **באתר המקורי הופיעו שני לוחות שעות שונים** — להחליט על אחד.
- תוכן: תיאורים ייחודיים לכל מוצר (חלק מהתיאורים מהמקור קצרים או זהים). זה הגורם המשפיע ביותר שנשאר בשליטתכם.
- תמונות: אחרי `catalog:mirror-images` לבדוק שה-alt של כל תמונה מתאר אותה.

## בכוונה לא מיושם
- דירוגי כוכבים: אין מערכת ביקורות אמיתית, ולכן אין `aggregateRating`. אפשר להוסיף כשיהיו ביקורות מאומתות.
- `shippingDetails` ב-Offer: יתווסף אחרי שמחירי המשלוח יוגדרו (אין להציג נתוני משלוח לא אמיתיים).
