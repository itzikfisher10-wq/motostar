# לפני העלייה לאוויר — מה חסר

רשימת ההחלטות, ההרשאות וההגדרות שאי אפשר להשלים בקוד. הן בידי בעל העסק.

## חובה
- [ ] **ספק סליקה:** חשבון PayPlus, מפתחות sandbox ואחר כך Production, ומעבר על רשימת הבדיקות ב-[payments.md](payments.md#רשימת-בדיקות-לפני-go-live-ב-sandbox). עד אז האתר לא יכול לגבות כסף.
- [ ] **אמצעי תשלום בקופה:** אחרי ההפעלה ב-PayPlus, עדכון `paymentMethods` ב-`src/config/site.ts`. היום מוצג "כרטיס אשראי" בלבד.
- [ ] **מחירי משלוח:** מחירי המשלוח של החנות הישנה לא היו זמינים. ממשק הניהול → משלוחים → מחיר וסף משלוח חינם → הפעלה. היום פעיל רק איסוף עצמי.
- [x] **תמונות:** כל 106 התמונות הועתקו לשרת שלנו, ו-`cdn.shopify.com` הוסר ([catalog-migration.md](catalog-migration.md#תמונות)).
- [ ] **אירוח:** פרויקט Vercel (או שרת), PostgreSQL מנוהל, Vercel Blob. ראו [deployment.md](deployment.md).
- [ ] **מיילים:** חשבון Resend ואימות דומיין שולח (SPF/DKIM) ל-`orders@motostar.co.il`, או כתובת אחרת.
- [ ] **משתמש ניהול ראשון** עם סיסמה חזקה.
- [ ] **תקנון ומדיניות פרטיות** (`src/content/pages.ts`): נלקחו מהאתר הישן ועודכנו. **צריך אישור של עורך דין**, כולל התאמה לחוק הגנת הצרכן ולתיקון 13 לחוק הגנת הפרטיות.
- [ ] **הצהרת נגישות** (`/info/accessibility`): להשלים את פרטי רכז/ת הנגישות ותאריך הבדיקה.
- [ ] **שעות פעילות:** באתר הישן הופיעו שני לוחות שעות שונים. היום מוצגות השעות מעמוד צור קשר. לאשר (`src/config/site.ts`).
- [ ] **12 מוצרים לבדיקה ידנית:** [catalog-migration.md](catalog-migration.md#12-הפריטים-שמחכים-להחלטה-שלכם).
- [ ] **מלאי:** הפיד הציבורי לא כלל כמויות. כדי שהמלאי ירד אוטומטית, מפעילים "ספירת מלאי" ומזינים כמויות. אפשרות נוספת: ייצוא CSV מ-Shopify.
- [ ] **אישור מפורש להעלאה לאוויר ולמעבר הדומיין** ([deployment.md](deployment.md#מעבר-הדומיין-מ-shopify-בלי-לאבד-תנועה-אורגנית)).

- [ ] **חומרי Arai:** תמונות, סרטון או רצף 360° מורשים (פנייה ליבואן או ל-Arai) לשדרוג אזור הדגל. היום הוא בנוי מתמונות החלפים מהקטלוג. ראו [editing-guide.md](editing-guide.md#אזור-arai).
- [ ] **לוגו רשמי** בקובץ SVG. היום מוצג לוגו טיפוגרפי.
- [ ] **התאמות לאופנועים:** לסמן "מאומת" לאחר בדיקה. כל ההתאמות שיובאו מסומנות "לפי המוכר".
- [ ] **SKU ייחודי** למשענות Xmax, שחולקות מק״ט במקור.
- [ ] **Google Search Console ו-Google Business Profile** ([seo.md](seo.md)).
- [ ] **גיבוי יומי עצמאי ובדיקת שחזור** ([security.md](security.md#מדיניות-גיבוי-ושחזור)).
- [ ] **שליחה חוזרת של מיילים שנכשלו** במשימה מתוזמנת ([deployment.md](deployment.md#משימות-מתוזמנות-מומלץ)).
- [ ] **מדידת ביצועים** באתר האמיתי עם תמונות ([performance.md](performance.md)).

## מה כבר מוכן
- קטלוג מלא: 71 מוצרים מ-79 רשומות. דוח כפילויות ואיחודים, הפניות 301 לכל הכתובות הישנות.
- חנות: קטגוריות, מותגים, מבצעים, חיפוש בעברית ובאנגלית עם שגיאות הקלדה, בחירת אופנוע, עמודי מוצר עם וריאציות ומפרט.
- סל וקופה: חישוב בשרת, משלוח, idempotency, עמוד סטטוס הזמנה, מיילים.
- תשלום: ממשק ספק, מימוש PayPlus ו-webhook מאובטח. נבדק עם ספק מדומה. **עדיין לא נבדק מול PayPlus אמיתי.**
- ממשק ניהול מלא עם הרשאות ויומן ביקורת.
- SEO טכני, נגישות (axe ללא הפרות חמורות), מובייל.
- פתיח בית עם קסדת תלת-ממד (איור, מסומן "להמחשה בלבד"), עם תמונת סטילס כגיבוי.
- בדיקות אוטומטיות: יחידה, אינטגרציה ו-E2E.
- תיעוד.
